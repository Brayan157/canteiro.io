# F00-03 — Metadados OpenAPI

- Estado: concluído
- Data: 2026-08-10

## Alteração

A especificação OpenAPI passa a identificar o produto como **Canteiro.io API**,
na versão atual `0.0.1-SNAPSHOT`, e descreve corretamente o MVP como API REST
de gestão financeira de obras para prestadores de serviço.

Referências herdadas a **ObraFlow**, incluindo domínio público e e-mail de
contato não confirmados, foram removidas. A configuração não inventa URL ou
canal de suporte: eles serão adicionados quando forem definidos pelo produto.

## Sem mudança de escopo

Esta alteração é somente de metadados de documentação. Endpoints, autenticação,
regras de domínio e caminhos da UI Swagger (`/swagger` e `/api-docs`) foram
preservados.
